One turn of the loop

The analyst proposes. The wrapper decides — and it re-measures rather than trusting a word of what the analyst reported.

Schedule Task Scheduler Every 4h from 16:00, hidden PowerShell, PT3H limit. A named mutex means two runs can never overlap; a crash marker dropped in a finally means a killed run is detected next wake and its half-edited main.py restored.
Field state automation.ps1 Submissions and episodes from Kaggle. The daily budget is counted from Kaggle's own UTC timestamps, not a local tally — the old local counter only ever incremented, so the loop would have improved forever and never shipped again.
Evidence loop.py Replays are indexed from their first 64KB — scores and team names serialise before steps, so a 17MB file is never parsed — then pruned to a 250MB corpus.
Selection loop.py select 3 worst losses + 2 field-best games + 2 near-misses. Deliberately not all of them: averaging the wins in is what hid that the best farm in the field scores twice ours.
Analysis claude -p, opus Non-interactive, permissions bypassed, web denied. Reads the prompt, memory.md in full, attempts.jsonl, the selected replays. Runs up to three distinct experiments before giving up.
Verdict automation.ps1 Code must differ from its snapshot, both ledgers must have been updated, py_compile and test_agent.py must pass, and the frozen benchmark is re-run against the frozen baseline.

What the loop cannot see

Worth knowing before trusting a green result.

Self-play is not the field

Both gates measure us against ourselves. Every real jump — fertilizing wheat, strawberry at field scale, the opening herd rush — came from reading a replay of a loss, never from the benchmark.

Ratings settle slower than the loop runs

A run is four hours; a rating needs 25–30 episodes. Submitting also retires an older agent, so the real constraint on shipping is convergence, not the five-a-day budget.

A single seed is noise

Both farms trade into one market, so any change moves the whole price path. Four seeds screen an idea; eight decide it. A 6/8 has flipped to 14/16 more than once.

Idle labour is not a signal

Four separate experiments freed up actions and lost money. The farm spends ~4,400 of ~7,000 actions a game walking, and freed actions became PASS, not revenue.
