Evidence-first, manually approved loop

The four-hour task only polls, downloads, summarizes, persists status, and notifies. It cannot call Claude, edit code, test, or submit.

  1. Check .automation/status.json.
  2. When evidence is ready, check /usage, then run .\automation.ps1 -ArmPlan -ConfirmUsageAbove50.
  3. Review .automation/proposals/<id>.md.
  4. Approve implementation/testing or reject the plan.
  5. If evaluation passes, separately approve the Kaggle submission.

See ARCHITECTURE.md for commands, gates, rollback guarantees, token limits, and the full state machine.
